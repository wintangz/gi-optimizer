### Compact Encoding & Invariants
- **Compact Source Representation**:
  - Elements indexed as `const ELE = ['anemo','geo','electro','hydro','pyro','cryo','dendro'] as const`.
  - Weapon types indexed as `const WT = ['sword','claymore','polearm','bow','catalyst'] as const`.
  - Raw character table encoded as a compact `Record<string, string>` (or `key:EWR` string pairs) where `c[0]` is element index `0..6`, `c[1]` is rarity `'4'|'5'`, and `c[2]` is weaponType index `0..4`.
  - Raw weapon table encoded as `Record<string, string>` where `w[0]` is weaponType index `0..4` and `w[1]` is rarity `'1'..'5'`.
  - Raw artifact set table encoded as `Record<string, string>` of rarity digits (e.g. `'45'`, `'34'`, `'123'`) hydrated into `rarities: readonly number[]`.
- **100% Parity Invariants**:
  - `ALL_CHARACTER_KEYS` matches `allCharacterKeys` from `@genshin-optimizer/gi/consts` in exact element membership.
  - `ALL_LOCATION_CHARACTER_KEYS` matches `allLocationCharacterKeys` (`[...nonTravelerCharacterKeys, 'Traveler']`).
  - `ALL_TRAVELER_KEYS` matches `allTravelerKeys`.
  - `ALL_WEAPON_KEYS` matches `allWeaponKeys`.
  - `ALL_ARTIFACT_SET_KEYS` matches `allArtifactSetKeys`.
  - `ALL_ARTIFACT_SLOT_KEYS` matches `allArtifactSlotKeys`.
  - `ALL_MAIN_STAT_KEYS` and `ALL_SUBSTAT_KEYS` match `allMainStatKeys` and `allSubstatKeys`.
  - `ART_MAX_LEVEL` matches `artMaxLevel` (`{ 1: 4, 2: 4, 3: 12, 4: 16, 5: 20 }`).
  - `ART_SLOT_MAIN_KEYS` matches `artSlotMainKeys`.
  - `charKeyToLocCharKey(charKey)` returns `'Traveler'` when `ALL_TRAVELER_KEYS.includes(charKey)` and `charKey` otherwise.

## 2. Zero-Dependency Preset Schema Contract (`packages/presets/src/schema.ts`)

Replaces `zod` with a lightweight, zero-dependency TypeScript validator while preserving the exact public types and `.parse()` / `.safeParse()` methods:

```ts
export const PRESET_SCHEMA_ID = 'gi-optimizer/preset@1' as const

export interface SchemaIssue {
  code: string
  path: Array<string | number>
  message: string
}

export interface SchemaError {
  issues: SchemaIssue[]
  message: string
}

export type SafeParseResult<T> =
  | { success: true; data: T; error?: undefined }
  | { success: false; data?: undefined; error: SchemaError }

export interface SchemaValidator<TOut, TIn = TOut> {
  parse(input: unknown): TOut
  safeParse(input: unknown): SafeParseResult<TOut>
  readonly _output: TOut
  readonly _input: TIn
}
```

### Exported Types & Schemas
- **Constants**: `PRESET_SCHEMA_ID = 'gi-optimizer/preset@1'`
- **Types**:
  - `PresetSource = 'akasha' | 'official' | 'user'`
  - `MemberRequirement`:
    - `constellation?: number | { min: number; max: number }` (int `0..6`)
    - `weapon?: { key: string; refinement?: number | { min: number; max: number } }` (`key` in `ALL_WEAPON_KEYS`, `refinement` int `1..5`)
    - `minLevel?: number` (int `1..100`)
    - `minTalent?: { auto?: number; skill?: number; burst?: number }` (each int `1..15`)
  - `TcCharacter`: `{ level: number (int 1..100); ascension: number (int 0..6); constellation: number (int 0..6); talent: { auto: number (int 1..15); skill: number (int 1..15); burst: number (int 1..15) } }`

  - `TcBuild`: `{ character: TcCharacter; weapon: TcWeapon; artifact: { slots: Record<'flower'|'plume'|'sands'|'goblet'|'circlet', { statKey: string (in ALL_MAIN_STAT_KEYS); level: number (int 0..20); rarity: number (int 1..5) }>; substats: { type: 'max'|'mid'|'min'; rarity: number (int 1..5); stats: Record<string, number> }; sets: Record<string, 1 | 2 | 4> } }`
  - `FixedBuild`: `{ type: 'fixed'; character: TcCharacter; weapon: TcWeapon }`
  - `TeamMember`:
    - `key: string` (in `ALL_CHARACTER_KEYS`)
    - `build: { type: 'owned' } | FixedBuild | { type: 'tc'; tc: TcBuild }`
    - `requirement: MemberRequirement` (default `{}`)
    - `conditional: Record<string, Record<string, string>>` (default `{}`)
    - `bonusStats: Record<string, number>` (default `{}`)
    - `infusionAura?: 'pyro' | 'cryo' | 'hydro' | 'electro'`
    - `hitMode: 'hit' | 'avgHit' | 'critHit' | 'global'` (default `'avgHit'`)
    - `reaction?: 'vaporize' | 'melt' | 'spread' | 'aggravate'`
  - `RotationTarget`:
    - `path: string[]` (length `>= 2`, `path[0] !== 'custom'`)
    - `count: number` (`> 0`, finite)
    - `label: string` (default `''`)
    - `hitMode: 'hit' | 'avgHit' | 'critHit' | 'global'` (default `'avgHit'`)
    - `reaction?: 'vaporize' | 'melt' | 'spread' | 'aggravate'`
    - `infusionAura?: 'pyro' | 'cryo' | 'hydro' | 'electro'`

  - `PresetInput`: Input type where defaulted fields are optional.

### Cross-Field Domain Refinements (`presetSchema`)
1. `if (p.team[0]?.key !== p.target)` → issue at `['team', 0, 'key']`: `'team[0] must be the target character'`
2. `if (p.source === 'akasha' && p.team[0]?.build.type !== 'fixed')` → issue at `['team', 0, 'build']`: `"akasha target member must use build.type 'fixed'"`
3. `if (p.source !== 'akasha' && p.team[0]?.build.type !== 'owned')` → issue at `['team', 0, 'build']`: `"target member must use build.type 'owned'"`
4. `if (new Set(p.team.map((m) => m.key)).size !== p.team.length)` → issue at `['team']`: `'duplicate team member'`
5. `if ((p.source === 'akasha') !== !!p.akasha)` → issue at `['akasha']`: `"akasha metadata is required for source 'akasha' and forbidden otherwise"`
6. `if (!p.id.startsWith(`${p.source}/`))` → issue at `['id']`: `'id prefix must match source'`
